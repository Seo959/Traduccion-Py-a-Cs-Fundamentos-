v0.7 - Reinicio: biblioteca en consola con archivos de texto

Ejecutar: dotnet run

IDEA
Se reinicia el proyecto desde la v0.7 con una estructura simple, parecida a la Practica Lab 4:
Program.cs (menu) + carpeta Biblioteca con dos modulos. Sin JSON, sin clases de datos, sin cifrado.
Los datos van en archivos .txt, una linea por registro, con campos separados por |

ESTRUCTURA
  Program.cs                   menu y pantallas
  Biblioteca/ModuloArchivo.cs  guardar y leer los .txt
  Biblioteca/ModuloClinica.cs  validaciones, busquedas y reporte

FUNCIONES
1. Registrar propietario (DNI de 8 numeros, no repetido)      -> propietarios.txt
2. Registrar mascota (dueño existente, edad 0 a 100)          -> mascotas.txt
3. Agendar cita (fecha, hora y turno libre)                   -> citas.txt
4. Buscar por nombre, DNI o especie
5. Ver reporte en pantalla
6. Exportar el reporte a reporte.txt

ERRORES QUE SE VAN A CORREGIR (marcados en el codigo)
1. Los .txt se guardan con ruta relativa
2. El DNI se muestra completo en el reporte
3. TurnoOcupado compara texto y no fechas
4. El telefono no se valida y el caracter | rompe el archivo
5. No se puede cancelar, editar ni eliminar nada todavia
