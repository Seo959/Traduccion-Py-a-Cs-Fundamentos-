ACTUALIZACIONES
1. Nuevo metodo LeerTexto: no deja campos vacios (nombre, especie, DNI).
2. Nuevo metodo DniValido: el DNI debe tener 8 numeros.
   Python (clinica_service.py, validar_propietario):
       if not dni.isdigit() or len(dni) != 8: raise ValueError("El DNI debe tener 8 números.")
3. Nuevo metodo DniRepetido: no se registran dos propietarios con el mismo DNI.
   Python: "Ya existe un propietario registrado con ese DNI."
4. Nuevo metodo MascotaRepetida: un dueño no puede tener dos mascotas con el mismo nombre.
   Python: "Ese propietario ya tiene una mascota con ese nombre."
5. Propietario.ObtenerDniProtegido(): el DNI se muestra como ******78.
   Python (models/entidades.py): "*" * (len(self.dni) - 2) + self.dni[-2:]
